# Analytical Notebooks

The notebooks form a sequential and reproducible analytical workflow for the mainland China inflation forecasting project.

Run the notebooks in numerical order. Each notebook loads its required files independently and should not depend on the in-memory state of an earlier notebook.

## Notebook order

1. `01_data_audit.ipynb`
2. `02_operational_benchmark.ipynb`
3. `03_sarima_development.ipynb`
4. `04_final_evaluation.ipynb`
5. `05_results_and_inference.ipynb`
